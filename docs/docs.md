# Техническое задание: Pomodoro CLI на TypeScript

## 1. Назначение проекта

Создать консольное приложение `pomo`, которое управляет Pomodoro-сессиями, сохраняет состояние между запусками и формирует статистику работы.

Проект является итоговой работой первого модуля Core JavaScript/Node.js. Основная цель — не сам таймер, а практическое понимание:

- выполнения JavaScript в Node.js;
- модулей ESM;
- функций, замыканий, объектов и массивов;
- асинхронности, event loop и таймеров;
- событий и сигналов процесса;
- файловой системы и потокового чтения;
- обработки ошибок;
- сериализации данных;
- тестирования без тяжёлого фреймворка;
- границы между TypeScript и JavaScript runtime.

## 2. Технологические ограничения

- Язык: TypeScript в режиме `strict`.
- Runtime: Node.js.
- Модули: ESM.
- Runtime-зависимости: отсутствуют.
- Разрешённая dev-зависимость: `typescript`.
- Тестирование: встроенные `node:test` и `node:assert/strict`.
- Разбор аргументов CLI выполняется самостоятельно через `process.argv`.
- Для файлов, путей, событий, streams и процессов используются встроенные модули `node:*`.

Запрещены в первой версии:

- Commander, Yargs, Inquirer;
- Chalk;
- Jest, Vitest;
- date-fns, Day.js;
- базы данных;
- веб-фреймворки;
- готовые библиотеки для Pomodoro или state machine.

Отсутствие runtime-зависимостей не означает отказ от архитектуры. Код должен быть разделён на доменную логику, сценарии использования, инфраструктуру и CLI.

## 3. Основные пользовательские сценарии

### 3.1 Запуск таймера

```bash
pomo start
pomo start --label "JavaScript closures"
pomo start --duration 40m
```

Поведение:

1. Загружается конфигурация.
2. Проверяется, нет ли уже активной сессии.
3. Создаётся focus-сессия.
4. Состояние атомарно сохраняется на диск.
5. В терминале показывается обратный отсчёт.
6. После завершения сессия добавляется в историю.
7. Пользователю предлагается или автоматически запускается перерыв.

### 3.2 Управление активной сессией

Пока таймер работает в foreground-режиме:

```text
[p] pause   [r] resume   [s] skip   [q] stop   [h] help
```

Команды должны обрабатываться через `stdin`. Если терминал поддерживает TTY, допускается raw mode. Для non-TTY окружения приложение продолжает работать без интерактивных клавиш.

### 3.3 Проверка состояния

```bash
pomo status
pomo status --json
```

Пример обычного вывода:

```text
FOCUS  18:42 remaining
Label: JavaScript closures
Cycle: 2 of 4
Status: running
```

### 3.4 Остановка и пропуск

```bash
pomo stop
pomo skip
```

- `stop` завершает текущую сессию как `interrupted`.

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.14. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
